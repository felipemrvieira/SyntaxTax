# Stack matrix

## Rodada A — API-first / microframeworks

- FastAPI + SQLAlchemy
- Sinatra + ActiveRecord
- Express + Prisma

## Rodada B — frameworks mais estruturados / opinionados

- Rails + ActiveRecord
- Django + ORM nativo
- NestJS + Prisma
- Spring Boot + JPA

## Regra

Cada stack deve ser implementada com o ORM e o framework aqui definidos. Não substituir ferramentas sem instrução explícita.
